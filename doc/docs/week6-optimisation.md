
# Week 6 — Advanced React and Campaign Optimisation

## 1. React application update

FreshFit uses React Router to provide these pages:

- Home
- Products
- Newsletter sign-up
- Campaign analytics dashboard

Reusable components include the product card and newsletter form.

The newsletter form uses React state, input validation,
and success and error messages.

The website layout adjusts to different screen sizes.

## 2. Landing-page variation

### Version A
Move better. Feel better.

### Version B
Find your fit for every move.

Both headlines communicate the FreshFit activewear idea
but use different wording.

## 3. A/B testing hypothesis

If the headline changes from "Move better. Feel better."
to "Find your fit for every move," the newsletter sign-up
rate may increase because the new headline directly
connects the brand to choosing activewear.

### Primary KPI
Newsletter sign-up conversion rate.

Calculation:

Number of newsletter sign-ups
divided by unique landing-page visitors
multiplied by 100.

### Testing method
1. Show Version A to one group of visitors.
2. Show Version B to another comparable group.
3. Keep other page elements consistent.
4. Record unique visitors and sign-ups.
5. Compare conversion rates.
6. Document the result before choosing a winner.

Do not claim a winning version until real test data
has been collected.

## 4. Usability testing

Ask 3–5 classmates to test the website.

### Tasks
1. Find the product collection.
2. Return to the home page.
3. Join the newsletter using a test email.
4. Find the campaign dashboard.

### Record for each task
- Was it completed without help?
- How long did it take?
- Did the participant experience confusion?
- What improvement did the participant suggest?

### Report
Summarise the actual feedback, identify repeated
problems, and record improvements made afterward.

Complete this report after conducting the tests.
